## Destination cards
These are authentic photographs of the listed Sri Lankan locations, selected from free-to-use photo pages on Unsplash.
The website uses remote images.unsplash.com URLs by default so it works with internet even without local JPG files.
Use `download-photos.ps1` only if you also want photos saved to `images/` (offline use).
Photographer acknowledgement is encouraged. Read [Unsplash License](https://unsplash.com/license) for terms.
