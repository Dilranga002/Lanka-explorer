**Week 05 checkpoint:** Week 04 plus My Trip localStorage, trip total per traveller, remove/clear, saved theme and dark mode.

## How to run
1. Open this `lanka-explorer` directory in Visual Studio Code.
2. Install the **Live Server** extension (Ritwick Dey).
3. Right-click `index.html` and choose **Open with Live Server**.
4. The browser opens a localhost URL, normally http://127.0.0.1:5500/.
5. If weather, maps, currency or remote photos do not load, check internet access.

For Week 03 onwards, do not double-click `index.html` with a file:// URL because `fetch()` needs a web server.
