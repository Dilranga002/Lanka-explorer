# Optional offline destination photos

The ten destination photos already work online using authentic Unsplash images.
To save local JPG copies, run the corrected `download-photos.ps1` in PowerShell.
If a download is blocked, the website keeps its online photo link; it never substitutes a broken local path.
To download manually, open PHOTO_CREDITS.md, visit the original photograph, click Download free, and save with the exact filename shown (e.g. sigiriya.jpg).

Photos are not included as binary JPG files in this ZIP.
